WhatsApp Reminders & Alerts
Before you press "Send Reminders": the three templates vel_fin_overdue_stage1, vel_fin_overdue_stage2 and vel_fin_overdue_stage3 must show Approved in MSG91. Until then only use Preview.
How it works: For every ACTIVE loan the system checks the installments.
• If the next EMI is due tomorrow → Advance Reminder (vel_fin_advance_reminder).
• If installments are overdue → a message by Stage with the exact overdue amount, the late fee and the total: Stage 1 → vel_fin_overdue_stage1, Stage 2 → vel_fin_overdue_stage2, Stage 3 and 4 → vel_fin_overdue_stage3.
• The same stage message is not repeated for 3 days (recorded in the Follow-ups table, so it works from any computer).
• Use Preview first to see exactly who will receive what.
